# Demo script (about 2 minutes)

**0:00–0:15 — Problem and boundary**  
“Public information can be correct and still be hard to act on. TrustWeave helps a communication team create a clear draft while showing its source and keeping a person in charge. This first version uses an educational hand-hygiene scenario.”

**0:15–0:35 — Intake**  
Enter the sample claim, select families/community volunteers, and choose a practical reminder. Add one cultural reference supplied for this brief. Explain that it is an optional signal, not a proxy for identity or a whole community.

**0:35–1:00 — Evidence and Qloo**  
Run the live workflow. Open the CDC source card and point to its retrieved excerpt and the narrow claim assessment. Show the Qloo-resolved entity and genre tags. State explicitly that these are aggregate affinity signals and are not evidence for the health claim.

**1:00–1:35 — Comparison**  
Show both editable drafts side by side. Explain that the baseline uses source material only and the context-aware version may use one Qloo-derived cue as a presentation idea. Make no claim that one is objectively better without evaluation evidence.

**1:35–1:55 — Review and trace**  
Show Gemini’s independent review notes, deterministic warnings, the workflow trace, and the source citation. Edit a phrase and export the human-review package.

**1:55–2:05 — Human control**  
Mark the message for further review. Close by noting that the app supports communication teams and does not replace public-health or emergency authorities.

Only use this script with a genuinely live provider run. If using sample mode, announce it as sample output and do not describe its cues as Qloo results.
