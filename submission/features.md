# Features

- Educational claim intake with audience and communication objective.
- Fixed-source CDC retrieval and bounded evidence assessment.
- Source title, page date, retrieved time, excerpt, and direct source link.
- Live Qloo entity search and Insights-based genre tags using a server-held event key.
- Gemini-generated baseline and context-aware messages displayed side by side and editable.
- Independent Gemini review, deterministic safety checks, source citation, and required human approval.
- Run trace, copy controls, and an exportable human-review package.
- Explicitly separate sample mode that makes no Qloo or Gemini calls.
- Responsive layout and server-side provider status checks.
