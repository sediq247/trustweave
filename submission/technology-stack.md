# Technology stack

- React 19 and Vite 8 for the browser application.
- Node.js 22+ and Express 5 for the same-origin API and production static hosting.
- Zod for request validation and bounded input sizes.
- Qloo event API: entity search and Insights taste analysis.
- Google Gemini Interactions API: message generation and independent quality review.
- Vitest for unit and mocked HTTP workflow tests.
- MIT license.

Runtime versions and API model availability should be rechecked during final deployment. Provider keys are server-side environment variables and are excluded from Git.
